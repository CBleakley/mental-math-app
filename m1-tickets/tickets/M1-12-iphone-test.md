# M1-12 iPhone field test and measurement

- **Status:** todo
- **Wave:** 5 (critical path)
- **Depends on:** M1-11
- **Unblocks:** Milestone 2

## Goal

Answer the milestone's question: is recognition good enough to keep going?

## Scope

- Run at least three 5-minute sessions on the iPhone in Safari.
- From the event log, count mishears and "sorry, again?" prompts.
- Check whether speech-start timestamps give believable answer times.
- Fix small issues found.
- Write up the results in the technical decisions doc.

## Done when

- [ ] A 5-minute session runs hands-free on the iPhone.
- [ ] The mishear rate and the timing verdict are written down.
